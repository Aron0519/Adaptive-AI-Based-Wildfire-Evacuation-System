# Adaptive-AI-Based-Wildfire-Evacuation-System

An AI-driven wildfire evacuation simulation developed in Unreal Engine 5 to study how civilians adapt their evacuation behavior to dynamically changing wildfire hazards.

Overview

This research project investigates adaptive AI decision-making and pathfinding in emergency evacuation scenarios. The simulation models civilians navigating an environment while responding to changing wildfire conditions.
The project compares traditional direct-route navigation with adaptive evacuation strategies that allow AI-controlled civilians to detect hazards, change routes, and respond to increasing danger.

Key Features

- Adaptive AI pathfinding for wildfire evacuation
- Dynamic hazard detection and route adaptation
- AI-controlled civilian behavior and panic responses
- Civilian health and survival tracking
- Wildfire hazard simulation using Unreal Engine 5
- Comparative evaluation of evacuation strategies
- Evacuation performance and survival metrics

Research

The simulation was used to compare direct-route navigation with adaptive evacuation strategies under wildfire conditions.
Results demonstrated that adaptive evacuation strategies improved survival outcomes compared to direct-route navigation.
